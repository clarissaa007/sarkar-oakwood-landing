# Sarkar Oakwood Launch

Create a single-product landing page for a new fragrance called OAKWOOD under the existing Sarkar Perfume brand.

IMPORTANT: This is a brand extension, not a rebranding.

The new fragrance must feel like it is an authentic existing Sarkar product. Keep the Sarkar brand identity, packaging, visual language, tone, aesthetic, and overall product presentation consistent with the existing Sarkar Perfume website.

Reference website:
https://sarkar.store/

Before designing the page, study the existing Sarkar website carefully and use it as the main visual reference.

MOST IMPORTANT REQUIREMENT

The existing Sarkar perfume packaging must remain EXACTLY THE SAME.

Do NOT:

redesign the bottle

redesign the label

change the Sarkar logo

change the bottle shape

change the packaging structure

create a completely different packaging style

introduce a new brand identity

The only new element is the fragrance: OAKWOOD.

Oakwood should look and feel like it belongs in the existing Sarkar Perfume collection.

LANDING PAGE PURPOSE

This should be a single scrolling landing page for the launch of Oakwood.

The goal is to:

Introduce Oakwood

Communicate its fragrance personality

Show the product

Explain the fragrance notes

Give the customer a reason to buy

End with a clear CTA

Do NOT turn this into a large e-commerce website with multiple pages.

HERO SECTION

Use the same visual language and aesthetic found on Sarkar's existing website.

Feature the Oakwood product prominently.

Text:

OAKWOOD

WHERE WARMTH MEETS CONFIDENCE.

Supporting copy:

"An earthy, warm fragrance crafted for those who leave a lasting impression."

CTA:

SHOP OAKWOOD

The product photography should feel like it belongs to Sarkar's existing product photography.

Do not create a completely different photography style for Oakwood.

FRAGRANCE INTRODUCTION

Heading:

MEET OAKWOOD

Copy:

"Oakwood is a warm, woody fragrance created for those who leave a lasting impression. Rich woods blend with soft amber and musk to create a scent that feels confident, effortless and timeless."

Keep the typography, spacing, colours and visual treatment consistent with Sarkar's existing website.

FRAGRANCE NOTES

Heading:

THE NOTES

Present the fragrance notes in a clean way that matches the existing Sarkar product presentation.

TOP NOTES
Bergamot · Black Pepper

HEART NOTES
Oakwood · Cedarwood · Sandalwood

BASE NOTES
Amber · Musk · Vanilla

Do not make this section look like a completely different brand.

PRODUCT SECTION

Show the Oakwood bottle using the same Sarkar packaging style.

Display:

OAKWOOD

50 ML

₹799

Short description:

"Your everyday signature scent, made to leave a lasting impression."

CTA:

SHOP OAKWOOD

Keep the product presentation consistent with Sarkar's existing products.

WHY OAKWOOD

Create a simple section communicating the fragrance personality:

WARM
Rich woody notes create a warm and inviting scent.

CONFIDENT
A distinctive fragrance designed to leave an impression.

TIMELESS
A versatile scent made for everyday wear.

Keep this section visually consistent with Sarkar's existing aesthetic.

FINAL CTA

End the landing page with:

MAKE OAKWOOD YOUR SIGNATURE.

"Discover a fragrance built around warmth, confidence and character."

CTA:

SHOP OAKWOOD

DESIGN RULES

The existing Sarkar website is the primary design reference.

Match its:

Colour palette

Typography style

Spacing

Image treatment

Product presentation

Button style

Overall mood

Brand tone

Minimalism

Visual hierarchy

The new fragrance should feel like Sarkar simply added one more perfume to its collection.

Do not make Oakwood look like a separate luxury perfume brand.

The final result should look as though Sarkar itself launched Oakwood as its newest fragrance.

Make the page:

Single-page

Responsive

Mobile-friendly

Fast-loading

Clean

Minimal

Easy to navigate

Consistent with the existing Sarkar brand

Prioritize brand consistency over creativity. The creativity should be in how Oakwood is introduced and sold, NOT in changing Sarkar's established visual identity.
